# Cryptomnesia

*Final Mobile Project for Mobile Dev Programming*


The application will be a hub to track and log your media consumption, it could be used to track goals, share with friends or just to have an archive of what you have been into. It's easy to forget what you thought about a movie you watched or if you read that book a long time ago, this fixes that you log what you consume and don't have to worry about that again. The intended user base are people that consume media, anyone. However the application would likely be geared towards younger people. A mobile application does the job here because it makes it easy to access, you don't want to have to log on to your computer or look up a website every time you finish an album you like.
